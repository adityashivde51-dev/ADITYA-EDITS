# ADITYA EDITS — Anime Video & XML Marketplace

Complete ready-to-run React + Vite + TypeScript web application for ADITYA EDITS.

## Quick Start (Beginner Friendly)

1. **Extract Zip**: Unzip this folder onto your computer.
2. **Install Node.js**: Ensure Node.js (v18+) is installed from https://nodejs.org/
3. **Open Terminal / Command Prompt**:
   - Navigate into the project folder.
   - Run: `npm install`
4. **Run Project**:
   - Run: `npm run dev`
   - Open the link shown in your terminal (e.g. `http://localhost:5173`) in Google Chrome.

## Configuration & Admin
- Switch between Customer & Admin views directly using the **Admin** button in the top navigation bar.
- Configure your Instagram link, UPI ID, and QR settings directly in `.env` or through the Admin Panel.

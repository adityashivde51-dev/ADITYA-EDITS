ADITYA EDITS — UPDATE NOTES

What this update changes:
1. Product catalogue metadata and order records are saved in this browser using localStorage.
2. Admin product rows now have Edit (title and INR price) and Delete actions.
3. Checkout now shows UPI (FamPay QR) as the only payment method.
4. New checkout orders are marked “Payment pending”; this demo does not pretend to verify a UPI payment.

Important current limitations:
- This is still a local browser demo. It is NOT yet an online website that can be managed from your phone anywhere.
- Product video, thumbnail, XML, ZIP and extra assets are selected in the form, but they are not uploaded to cloud storage. Temporary browser file URLs do not survive refresh; only products with durable non-blob URLs are saved in the catalogue.
- UPI QR image display, payment proof review, customer login, protected downloads, real order/customer database, and online admin access are NOT connected yet.
- Do not publish this demo as a real paid store until authentication, cloud storage, order security and payment confirmation are implemented and tested.

Next implementation stage:
Connect Firebase Authentication (admin sign-in), Firestore (products/orders/settings), Firebase Storage (video/thumbnail/XML/ZIP), then deploy the site. This requires creating a Firebase project and adding its public web-app config. Never put private service-account keys in frontend code. If cloud billing is requested, ask a parent/guardian to review it first.

Run locally (from this project folder):
  npm.cmd install
  npm.cmd run dev

Then open the localhost URL printed by Vite. Keep the terminal running while testing.
